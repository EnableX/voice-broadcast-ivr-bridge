• Broadcast IVR DTMF Bridge
1
Install dependencies
npm install
2
Configure credentials
cp env-example .env

Edit .env and fill in ENABLEX_APP_ID, ENABLEX_APP_KEY, and set LISTEN_SSL=false.

3
Create an ngrok tunnel
ngrok http 3000

Copy the https://…ngrok.io URL and set it as PUBLIC_WEBHOOK_URL in .env.

4
Start the server
npm start

Open http://localhost:3000 and use the form below to place a call.

    IVR Call Flow
    Broadcast call connects (per recipient)
  └─▶ welcome_prompt plays
        └─▶ ivr_prompt plays  (waits for digit)
              ├─ Digit 1 ──▶ bridge_announcement_1
              │                └─▶ Bridge to Digit-1 Number
              ├─ Digit 2 ──▶ bridge_announcement_2
              │                └─▶ Bridge to Digit-2 Number
              ├─ Wrong   ──▶ wrong_digit_prompt
              │                └─▶ ivr_prompt  (retry++)
              └─ Timeout ──▶ timeout_prompt
                               └─▶ ivr_prompt  (retry++)
                                      ↓ after 3 attempts
                               max_retry_prompt ──▶ Hangup
